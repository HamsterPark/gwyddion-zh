# Gwyddion 中文本地化

为开源扫描探针显微数据分析软件 [Gwyddion](https://gwyddion.net/) 制作可供社区使用、并计划向上游贡献的中文界面翻译：简体中文（中国大陆）、繁體中文（香港／澳門）和繁體中文（台灣）。

## 当前状态

项目处于审校与界面测试阶段：简体合并稿及台湾、香港两版繁体稿均已完成全文分段审校和地区用语复核（各 5,052/5,053 条，`Volume` 暂留空），尚无经过完整界面测试的正式语言包。以 Gwyddion 2.71 稳定版的官方翻译模板为基准；现有本机 2.67 不能作为最终验收版本。上游模板来源：[Gwyddion 2.71 源码](https://gwyddion.net/download/2.71/)。开发版更新与未来版本应在合并前核对。

## 工作计划

1. 固定翻译模板，建立专业术语表并按上下文划分工作。
2. 分批翻译：Codex 负责核心界面、专业难项和共享条目；Grok 负责文件导入导出；DeepSeek 负责其他模块。难项分配需人工复核，各组不得重复翻译同一条目。
3. 汇总简体译文并制作香港／澳门和台湾繁体版本；分别审校地区术语、用字和界面习惯，澳门有差异的部分单独记录，不能仅依靠自动转换。
4. 分别核对各地区译文完整性、科学含义、术语、占位符、格式标签及快捷键；编译语言包，在 Gwyddion 2.71 中测试显示和布局。
5. 对照上游最新模板更新和复核，依据上游贡献流程准备提交；与社区沟通和提交事宜由项目参与者完成。

## 地区版本

- `zh_CN`：简体中文（中国大陆）。
- `zh_HK`：繁體中文（香港），作为香港／澳门的初始基础；澳门地区差异待审校后确定是否另建 `zh_MO`，并验证上游支持与回退行为。
- `zh_TW`：繁體中文（台灣）。

三种地区译文分别维护，保留共同术语与差异记录；繁体稿已完成全文分段审校和地区用语复核，仍建议台湾／香港母语者终审。实际语言选择和 Windows 加载方式仍待测试。

分片脚本 `node split-template.cjs` 可从固定模板重新生成空白分片；不要对已翻译文件运行覆盖操作。
