# 翻译草稿与检查

`zh_CN.po` 是简体中文合并初稿；Codex 负责的批次已初译，其余条目等待 Grok、DeepSeek 交回，所有译文仍需术语和界面审校。个别含义有歧义的项目暂时留空。

`zh_HK.po` 和 `zh_TW.po` 是使用 OpenCC 从当前简体初稿自动转换的**未审校草稿**，不是完成的地区本地化。转换条目全部标记为 fuzzy，常规 gettext 编译会跳过这些条目。需要懂香港／澳门及台湾用语的审校者逐项核对术语、惯用字、标点与界面长度，通过后才能移除对应 fuzzy。澳门是否需要单独 `zh_MO` 待实际地区差异及上游支持确认。

## 合并与检查

在项目根目录安装 `requirements.txt` 中的依赖，然后运行：

```sh
python check_batches.py
python merge_drafts.py
```

检查脚本核对批次原文键、格式标记、常见 printf 和 Gwyddion 占位符及标签；它并不能替代 GNU `msgfmt --check`、领域审校或实际运行测试。合并脚本以固定模板为准，只导入批次译文。**合并脚本会覆盖本目录三个草稿**；手工审校前需保存审校成果，并调整合并流程以保护它们。地区版本当前不可作为发布版本。

`work/` 下的各 PO 是简体翻译工作底稿；未翻译和有歧义的条目保留空白。归档尚未返回的外部批次时请遵循 [交接说明](../HANDOFF.md)，先进行检查再合并。
